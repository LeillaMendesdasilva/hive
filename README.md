# Hive
O Hive é uma plataforma online de venda e gestão de jogos, inspirada na Steam. Desenvolvida com HTML, CSS, JavaScript e Python, permite que clientes comprem, avaliem e comentem jogos, enquanto desenvolvedores podem cadastrar e acompanhar o desempenho de seus títulos. Um administrador gerencia todo o sistema e seus dados.

A estrutura do banco de dados conta com entidades como Usuário, Jogo, Compra, Biblioteca e Avaliação, garantindo controle e organização das funcionalidades. O projeto oferece uma experiência completa para jogadores, desenvolvedores e administradores em um ambiente seguro e funcional.
